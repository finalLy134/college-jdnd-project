# college-jdnd-project
A DnD project I made for college in Java, pretty simple but was really fun to work on.

If you want to run it just download the source code of the repo, extract it, then navigate to that folder into /out/run.bat and run it.
I compiled it on JDK 21 so if it doesn't work you probably need to install JDK 21 or just rebuild the project, i made it in Eclipse IDE.
